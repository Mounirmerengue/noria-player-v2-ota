# Noria Player V2 — OTA

Manifeste de mise à jour et APK de release pour Noria Player V2.

Ce dépôt ne contient pas de code source : uniquement `update.json` et les
APK publiés en release, que l'application lit pour se mettre à jour.

## Quel APK choisir

| Fichier | Pour |
|---|---|
| `arm64-v8a` | La plupart des box Android TV récentes — à privilégier |
| `armeabi-v7a` | Box plus anciennes, Fire Stick |
| `x86_64` | Émulateurs |
| `universal` | Fonctionne partout, mais lourd (peut échouer si le stockage est limité) |
